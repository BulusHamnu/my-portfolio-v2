# Bulus Hamnu Portfolio v2

## Overview

This is the second version of my developer portfolio, rebuilt with React and TypeScript to reflect my growth from basic frontend development into backend engineering and modern web application development.

The portfolio showcases my projects, technical skills, experience, education, and contact information in a more modern and interactive interface.

---

## Tech Stack

- React
- TypeScript
- Vite
- Framer Motion
- React Icons

---

## Features

- Responsive modern UI
- Animated sections using Framer Motion
- Project showcase with live demo and code links
- Skills section
- About / experience / education section
- Mobile-friendly layout
- Formspree contact integration

---

## Differences From Previous Version

Compared to the first portfolio version (built with HTML, CSS, and JavaScript), this version introduces:

- React-based architecture
- Improved UI design and layout
- Better component structure
- TypeScript integration
- Modern animation system
- Cleaner project presentation
